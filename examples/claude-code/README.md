# Claude Code workflow examples

Examples of Claude Code sessions following the workflows defined in this repository. These represent real operational patterns — not demonstrations of AI capability.

---

## What these examples show

Each example shows a representative session using a defined workflow. The examples include:
- The context provided to the model
- The model's output
- The engineer's validation steps and modifications
- The final outcome

Examples are not cherry-picked best-case outputs. They reflect typical quality when workflows are followed correctly — including the validation and correction steps that are part of the process.

---

## Redaction notice

All examples are redacted for sensitive information: credentials, PII, internal service names that would identify specific production systems, and live production data. The technical patterns and engineering judgments reflect real usage.
